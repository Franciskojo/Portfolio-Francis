# Portfolio Website - Full Stack Developer

A professional portfolio website built with React, showcasing full-stack development expertise with strong backend focus. Features modern design, smooth animations, and responsive layout.

![Portfolio Screenshot](https://via.placeholder.com/800x400/0a192f/64ffda?text=FullStack+Developer+Portfolio)

## 🚀 Features

- **Modern Design**: Clean, professional dark theme with accent colors
- **Responsive**: Fully responsive design for all devices
- **Smooth Animations**: Powered by Framer Motion for engaging interactions
- **Professional Sections**:
  - Hero section with tech stack
  - Projects showcase with detailed case studies
  - About section with skills and experience
  - Contact form with validation
  - Professional footer with social links

## 🛠 Tech Stack

### Frontend
- **React** - UI framework
- **React Router DOM** - Client-side routing
- **Framer Motion** - Animations and transitions
- **React Icons** - Icon library

### Styling
- **CSS3** with custom properties
- **CSS Grid & Flexbox** - Modern layout techniques
- **Responsive Design** - Mobile-first approach

### Development Tools
- **Vite** - Build tool and dev server
- **Git** - Version control
